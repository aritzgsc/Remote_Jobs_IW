ACCESO CON GOOGLE

Falta activar Google OAuth

El botón ya está disponible, pero esta instalación todavía no tiene las credenciales de Google necesarias para iniciar sesión. Puedes seguir entrando con correo y contraseña mientras lo configuras.

  1. Entra en Google Cloud Console y crea un cliente OAuth de tipo Aplicación web.
  2. Añade esta URI de retorno a los URI de redirección autorizados:
    http://127.0.0.1:8000/accounts/google/login/callback/
  3. Copia el ID y el secreto del cliente en el archivo .env del proyecto: 
                    GOOGLE_OAUTH_CLIENT_ID=tu-client-id
                    GOOGLE_OAUTH_CLIENT_SECRET=tu-client-secret

Reinicia el servidor Django después de guardar el archivo. Para probar Google desde el móvil necesitarás una URL HTTPS autorizada; la IP local de la Wi-Fi no sirve como callback de Google.
